# Industrial Brutalist UI Redesign — Hospital Greguito

## Archetype: Tactical Telemetry & CRT Terminal (Dark Mode)

A full visual overhaul of the hospital management system applying the Industrial Brutalist design system — dark terminal aesthetic, monospaced typography, razor-thin grid borders, ASCII decorations, and CRT scanline textures. Zero gradients, zero border-radius, zero glassmorphism.

## Design Principles Applied

1. **Zero border-radius** — all corners are 90°
2. **Visible grid borders** — `1px solid #333` separating all zones
3. **Monospace everything** — data, labels, timestamps, status
4. **Uppercase macro-text** — page titles at massive scale with tight tracking
5. **Red-only accent** — `#E61919` as the sole color accent
6. **ASCII decorations** — `[ BRACKETS ]`, `>>>`, `+` crosshairs
7. **CRT scanlines** — subtle repeating gradient overlay
8. **Mechanical noise** — SVG filter for physical grain texture
9. **No gradients, no blur, no translucency** — pure flat surfaces
