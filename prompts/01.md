Crie uma aplicação para Gestão de Hospital contendo um cadastro de pacientes, cadastro de medicamentos, agendamento de cirurgias, cadastro de materiais para cirurgia, cadastro de prontuário, reserva de leitos, cadastro de médicos e especialidades, cadastro de funcionários, agendamento de consultas.

Deve haver um formulário inicial com autenticação para o login dos funcionários.
Deve haver um formulário para agendamento de consultas. 
Deve haver um formulário para agendamento de cirurgias.
Deve haver um formulário para cadastro de funcionários.
Deve haver um formulário para cadastro de médicos.

# Constraints

- Use React Hook Form com Zod para validar formulários.
- Utilize a biblioteca `react-pdf` para exibir arquivos PDF.
- Use shadows/ui como biblioteca de componentes para estilização.
- Use Tailwind CSS para a estilização.
- Use Next.js App Router para navegação entre páginas e TypeScript para tipagem.
- Utilize Prisma Postgres para gerenciar o banco de dados de usuários e documentos.
- Utilize React Icons para os icones.

# MCPs

- Use Context7 para buscar documentação.
